# 2️⃣ Prefix, Suffix, and Subarray Logic

## 🎯 Introduction: What are Prefixes, Suffixes, and Subarrays?

**Real-life analogy:** Think of a book:
- 📖 **Prefix** = Reading from the beginning up to some page
- 📖 **Suffix** = Reading from some page to the end
- 📖 **Subarray** = Reading any continuous section of pages

## 📚 Part 1: Understanding Prefixes

### What is a Prefix?

A **prefix** is everything from the **start** up to a certain position.

```
Array: [5, 3, 8, 2, 7]
Index:  0  1  2  3  4

Prefix of length 1: [5]
                    └─┘

Prefix of length 2: [5, 3]
                    └────┘

Prefix of length 3: [5, 3, 8]
                    └────────┘

Prefix of length 4: [5, 3, 8, 2]
                    └────────────┘

Prefix of length 5: [5, 3, 8, 2, 7]  (entire array)
                    └────────────────┘
```

---

### Visual: Prefix as Reading Progress

```
Book pages: [P1] [P2] [P3] [P4] [P5]

After reading 1 page:
[P1]
 ✓

After reading 2 pages:
[P1] [P2]
 ✓    ✓

After reading 3 pages:
[P1] [P2] [P3]
 ✓    ✓    ✓

Pattern: Always starts from beginning!
```

## 🧮 Prefix Sum: The Most Important Concept

### What is Prefix Sum?

**Prefix sum** at position `i` = Sum of all elements from start to position `i`.

```
Array:      [5,  3,  8,  2,  7]
Index:       0   1   2   3   4

Prefix sum calculation:
Position 0: 5                    = 5
Position 1: 5 + 3                = 8
Position 2: 5 + 3 + 8            = 16
Position 3: 5 + 3 + 8 + 2        = 18
Position 4: 5 + 3 + 8 + 2 + 7    = 25

Prefix sum: [5,  8,  16, 18, 25]
```

---

### Visual: Building Prefix Sum Step by Step

```
Step-by-step accumulation:

Array:    [5]  [3]  [8]  [2]  [7]
           ↓
Sum:      [5]
           ↓
           └──→ [3]
                 ↓
Sum:      [5]  [8]
                ↓
                └──→ [8]
                      ↓
Sum:      [5]  [8]  [16]
                     ↓
                     └──→ [2]
                           ↓
Sum:      [5]  [8]  [16] [18]
                          ↓
                          └──→ [7]
                                ↓
Sum:      [5]  [8]  [16] [18] [25]

Each position = previous sum + current element
```

### Code: Calculate Prefix Sum

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr = {5, 3, 8, 2, 7};
    int n = arr.size();

    vector<int> prefix(n);
    
    prefix[0] = arr[0];  // First element stays same
    
    for (int i = 1; i < n; i++) {
        prefix[i] = prefix[i-1] + arr[i];
    }
    
    // Display results
    cout << "Original array:\n";
    cout << "Index:  ";
    for (int i = 0; i < n; i++) cout << i << "   ";
    cout << "\n";
    
    cout << "Value:  ";
    for (int i = 0; i < n; i++) cout << arr[i] << "   ";
    cout << "\n\n";
    
    cout << "Prefix sum array:\n";
    cout << "Index:  ";
    for (int i = 0; i < n; i++) cout << i << "   ";
    cout << "\n";
    
    cout << "Value:  ";
    for (int i = 0; i < n; i++) {
        if (prefix[i] < 10) cout << prefix[i] << "   ";
        else cout << prefix[i] << "  ";
    }
    cout << "\n";
    
    // Show what each prefix sum represents
    cout << "\nMeaning:\n";
    for (int i = 0; i < n; i++) {
        cout << "prefix[" << i << "] = " << prefix[i];
        cout << " (sum of arr[0.." << i << "])\n";
    }
    
    return 0;
}
```

## 🎯 Why Prefix Sum is Powerful: Range Queries

### The Magic Formula

**To find sum of any range [L, R]:**

```
Sum(L, R) = prefix[R] - prefix[L-1]

Special case: If L = 0, then Sum(0, R) = prefix[R]
```

---

### Visual: Range Sum Using Prefix

```
Array:      [5,  3,  8,  2,  7]
Index:       0   1   2   3   4

Prefix sum: [5,  8, 16, 18, 25]

Question: What is sum of arr[1..3]?
          (Sum of elements at indices 1, 2, 3)

Traditional way:
arr[1] + arr[2] + arr[3] = 3 + 8 + 2 = 13

Using prefix sum:
Sum(1, 3) = prefix[3] - prefix[0]
          = 18 - 5
          = 13  ✓

Visual explanation:
prefix[3] = sum(0..3) = 5+3+8+2 = 18
prefix[0] = sum(0..0) = 5

Subtract: 18 - 5 = 13 (which is 3+8+2)

          [5,  3,  8,  2,  7]
           ↑   └────────┘
        Remove   Keep this part
```

---

### Code: Range Sum Query

```cpp
#include <iostream>
#include <vector>
using namespace std;

class PrefixSum {
    vector<int> prefix;
    
public:
    PrefixSum(vector<int>& arr) {
        int n = arr.size();
        prefix.resize(n);
        
        prefix[0] = arr[0];
        for (int i = 1; i < n; i++) {
            prefix[i] = prefix[i-1] + arr[i];
        }
    }
    
    int rangeSum(int L, int R) {
        if (L == 0) {
            return prefix[R];
        }
        return prefix[R] - prefix[L-1];
    }
    
    void printPrefix() {
        cout << "Prefix sum: ";
        for (int x : prefix) cout << x << " ";
        cout << "\n";
    }
};

int main() {
    vector<int> arr = {5, 3, 8, 2, 7};
    
    cout << "Array: ";
    for (int x : arr) cout << x << " ";
    cout << "\n";
    
    PrefixSum ps(arr);
    ps.printPrefix();
    
    cout << "\nRange sum queries:\n";
    cout << "─────────────────\n";
    
    // Query 1: Sum of arr[0..2]
    cout << "Sum(0, 2) = " << ps.rangeSum(0, 2) << "\n";
    cout << "  (5 + 3 + 8 = 16) ✓\n\n";
    
    // Query 2: Sum of arr[1..3]
    cout << "Sum(1, 3) = " << ps.rangeSum(1, 3) << "\n";
    cout << "  (3 + 8 + 2 = 13) ✓\n\n";
    
    // Query 3: Sum of arr[2..4]
    cout << "Sum(2, 4) = " << ps.rangeSum(2, 4) << "\n";
    cout << "  (8 + 2 + 7 = 17) ✓\n";
    
    return 0;
}
```

**Output:**
```
Array: 5 3 8 2 7
Prefix sum: 5 8 16 18 25

Range sum queries:
─────────────────
Sum(0, 2) = 16
  (5 + 3 + 8 = 16) ✓

Sum(1, 3) = 13
  (3 + 8 + 2 = 13) ✓

Sum(2, 4) = 17
  (8 + 2 + 7 = 17) ✓
```

```cpp
    return 0;
}
```

## 🔄 Part 2: Understanding Suffixes

### What is a Suffix?

A **suffix** is everything from a certain position to the **end**.

```
Array: [5, 3, 8, 2, 7]
Index:  0  1  2  3  4

Suffix starting at 0: [5, 3, 8, 2, 7]  (entire array)
                      └────────────────┘

Suffix starting at 1: [3, 8, 2, 7]
                         └──────────┘

Suffix starting at 2: [8, 2, 7]
                            └──────┘

Suffix starting at 3: [2, 7]
                               └────┘

Suffix starting at 4: [7]
                                  └─┘
```

---

```
Book chapters: [C1] [C2] [C3] [C4] [C5]

Starting from chapter 1:

Starting from chapter 2:
```

## 🧮 Suffix Sum

### What is Suffix Sum?

**Suffix sum** at position `i` = Sum of all elements from position `i` to end.

```
Array:      [5,  3,  8,  2,  7]
Index:       0   1   2   3   4

Suffix sum calculation:
Position 0: 5 + 3 + 8 + 2 + 7    = 25
Position 1:     3 + 8 + 2 + 7    = 20
Position 2:         8 + 2 + 7    = 17
Position 3:             2 + 7    = 9
Position 4:                 7    = 7

Suffix sum: [25, 20, 17, 9,  7]
```

---

### Visual: Building Suffix Sum

```
Build from RIGHT to LEFT:

Array:    [5]  [3]  [8]  [2]  [7]
                                ↓
Suffix:                        [7]
                           ↓
                      [2]  ←┘
                       ↓
Suffix:              [9]  [7]
                  ↓
             [8]  ←┘
              ↓
Suffix:     [17] [9]  [7]
         ↓
    [3]  ←┘
     ↓
Suffix: [20][17] [9]  [7]
     ↓
[5]  ←┘
 ↓
Suffix:[25][20][17] [9]  [7]
```

---

### Code: Calculate Suffix Sum

```cpp
#include <iostream>

    for (int i = 0; i < n; i++) cout << i << "   ";
    cout << "\n";
    
    cout << "Value:  ";

        if (suffix[i] < 10) cout << suffix[i] << "   ";
        else cout << suffix[i] << "  ";
    }
    cout << "\n";
    
    // Show what each suffix sum represents
    cout << "\nMeaning:\n";
    for (int i = 0; i < n; i++) {
        cout << "suffix[" << i << "] = " << suffix[i];
        cout << " (sum of arr[" << i << ".." << (n-1) << "])\n";
    }
    
    return 0;
}
```

## 🎯 Combining Prefix and Suffix

### Finding Split Point

**Problem:** Split array into two parts with equal sum.

```
Array: [1, 3, 4, 2, 2]

Check each split point:

Split after index 0:
Left:  [1]           sum = 1
Right: [3, 4, 2, 2]  sum = 11  ✗

Split after index 1:
Left:  [1, 3]        sum = 4
Right: [4, 2, 2]     sum = 8   ✗

Split after index 2:
Left:  [1, 3, 4]     sum = 8
Right: [2, 2]        sum = 4   ✗

Split after index 3:
Left:  [1, 3, 4, 2]  sum = 10
Right: [2]           sum = 2   ✗

No equal split exists!
```

---

### Visual: Split Point Analysis

```
Array: [2, 1, 1, 2]

Prefix sum:  [2, 3, 4, 6]
Suffix sum:  [6, 4, 3, 2]

Check each position:
Position 0: prefix[0]=2  suffix[1]=4  ✗
```

### Code: Find Equal Split

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr = {2, 1, 1, 2};
    int n = arr.size();
    
    // Calculate prefix sum
    vector<int> prefix(n);
    prefix[0] = arr[0];
    for (int i = 1; i < n; i++) {
        prefix[i] = prefix[i-1] + arr[i];
    }
    
    // Calculate suffix sum
    vector<int> suffix(n);
    suffix[n-1] = arr[n-1];
    for (int i = n - 2; i >= 0; i--) {
        suffix[i] = suffix[i+1] + arr[i];
    }
    
    cout << "Array:      ";
    for (int x : arr) cout << x << " ";
    cout << "\n";
    
    cout << "Prefix sum: ";
    for (int x : prefix) cout << x << " ";
    cout << "\n";
    
    cout << "Suffix sum: ";
    for (int x : suffix) cout << x << " ";
    cout << "\n\n";
    
    cout << "Checking split points:\n";
    cout << "─────────────────────\n";
    
    bool found = false;
    
    for (int i = 0; i < n - 1; i++) {
        int leftSum = prefix[i];
        int rightSum = suffix[i+1];
        
        cout << "After index " << i << ": ";
        cout << "Left sum = " << leftSum << ", ";
        cout << "Right sum = " << rightSum;
        
        if (leftSum == rightSum) {
            cout << " ✓ EQUAL!";
            found = true;
        }
        cout << "\n";
    }
    
    if (!found) {
        cout << "\nNo equal split found.\n";
    } else {
        cout << "\nEqual split exists!\n";
    }
    
    return 0;
}
```

```

Suffix sum: 6 4 3 2

─────────────────────
```

## 📦 Part 3: Understanding Subarrays

### What is a Subarray?

A **subarray** is any **contiguous** (consecutive) portion of the array.

```
Array: [5, 3, 8, 2, 7]

Examples of subarrays:
[5]           ✓ (from index 0 to 0)
[3, 8]        ✓ (from index 1 to 2)
[8, 2, 7]     ✓ (from index 2 to 4)
[5, 3, 8, 2]  ✓ (from index 0 to 3)

NOT subarrays:
[5, 8]        ✗ (skips element at index 1)
[3, 2]        ✗ (not consecutive in array)
[7, 5]        ✗ (wrong order)
```

---

### Visual: All Possible Subarrays

```
Array: [A, B, C]

Length 1 subarrays:
[A]
    [B]
        [C]

Length 2 subarrays:
[A, B]
    [B, C]

Length 3 subarrays:
[A, B, C]

Total: 6 subarrays
Formula: n*(n+1)/2 where n=3
        = 3*4/2 = 6 ✓
```

## 🎯 Subarray Sum Using Prefix Sum

### Fast Subarray Sum Query

Instead of adding elements every time, use prefix sum!

```
Array:      [5, 3, 8, 2, 7]
Prefix sum: [5, 8, 16, 18, 25]

Q: Sum of subarray [1..3]?

Traditional: arr[1] + arr[2] + arr[3]
           = 3 + 8 + 2 = 13

Using prefix:
Sum(1, 3) = prefix[3] - prefix[0]
          = 18 - 5
          = 13 ✓

Time: O(1) instead of O(n)!
```

---

### Visual: Subarray Sum Calculation

```
Array:      [5,  3,  8,  2,  7]
Index:       0   1   2   3   4
Prefix:     [5,  8, 16, 18, 25]

Find sum of [1..3]:

Step 1: Get prefix[3] = 18
        This is sum(0..3) = 5+3+8+2

Step 2: Get prefix[0] = 5
        This is sum(0..0) = 5

Step 3: Subtract
        18 - 5 = 13
        This removes the "5" leaving us with 3+8+2

Visual:
sum(0..3) = [5, 3, 8, 2] = 18
             └─┘
           Remove this (=5)
           
Remaining = [3, 8, 2] = 13 ✓
```

---

### Code: Efficient Subarray Sum

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr = {5, 3, 8, 2, 7};
    int n = arr.size();
    
    // Build prefix sum
    vector<int> prefix(n);
    prefix[0] = arr[0];
    for (int i = 1; i < n; i++) {
        prefix[i] = prefix[i-1] + arr[i];
    }
    
    cout << "Array:      ";
    for (int x : arr) cout << x << " ";
    cout << "\n";
    
    cout << "Prefix sum: ";
    for (int x : prefix) cout << x << " ";
    cout << "\n\n";
    
    // Test subarray sum queries
    vector<pair<int,int>> queries = {{0, 2}, {1, 3}, {2, 4}, {0, 4}};
    
    cout << "Subarray sum queries:\n";
    cout << "────────────────────\n";
    
    for (auto& q : queries) {
        int L = q.first;
        int R = q.second;
        
        int sum = (L == 0) ? prefix[R] : prefix[R] - prefix[L-1];
        
        cout << "Sum[" << L << ".." << R << "] = " << sum << "  ";
        
        // Verify by showing elements
        cout << "(";
        for (int i = L; i <= R; i++) {
            cout << arr[i];
            if (i < R) cout << "+";
        }
        cout << ")\n";
    }
    
    return 0;
}
```

### Code: Kadane's Algorithm (Maximum Subarray)

```cpp
#include <iostream>
#include <vector>
#include <climits>
using namespace std;

int main() {
    vector<int> arr = {-2, 1, -3, 4, -1, 2, 1, -5, 4};
    int n = arr.size();
    
    int maxSum = INT_MIN;
    int currentSum = 0;
    int start = 0, end = 0, tempStart = 0;
    
    cout << "Array: ";
    for (int x : arr) cout << x << " ";
    cout << "\n\n";
    
    cout << "Step-by-step process:\n";
    cout << "─────────────────────\n";
    
    for (int i = 0; i < n; i++) {
        currentSum += arr[i];
        
        cout << "i=" << i << ", arr[" << i << "]=" << arr[i];
        cout << ", currentSum=" << currentSum;
        
        if (currentSum > maxSum) {
            maxSum = currentSum;
            start = tempStart;
            end = i;
            cout << " → New max!";
        }
        
        if (currentSum < 0) {
            currentSum = 0;
            tempStart = i + 1;
            cout << " → Reset (negative)";
        }
        
        cout << "\n";
    }
    
    cout << "\n━━━━━━━━━━━━━━━━━━━━━\n";
    cout << "Maximum subarray sum: " << maxSum << "\n";
    cout << "Subarray indices: [" << start << ".." << end << "]\n";
    cout << "Elements: [";
    for (int i = start; i <= end; i++) {
        cout << arr[i];
        if (i < end) cout << ", ";
    }
    cout << "]\n";
    
    return 0;
}
```

## 🎯 Part 4: Majority Element in Subarray

### What is Majority?

An element is **majority** if it appears more than `n/2` times.

```
Array: [3, 3, 4, 2, 3]
Length: 5
n/2 = 2.5, so need > 2 occurrences

Element 3 appears 3 times > 2.5 ✓ MAJORITY
Element 4 appears 1 time  < 2.5 ✗
Element 2 appears 1 time  < 2.5 ✗

Majority element: 3
```

---

### Visual: Counting Frequency

```
        ↓  ↓     ↓
Count:  1  2  0  0  3

Element 4: █   (1 occurrence)
Element 2: █   (1 occurrence)

```

### Code: Find Majority Element (Boyer-Moore Algorithm)

```cpp
#include <iostream>
#include <vector>
using namespace std;

int findMajority(vector<int>& arr) {
    int candidate = arr[0];
    int count = 1;
    
    cout << "Finding candidate:\n";
    cout << "──────────────────\n";
    
    for (int i = 1; i < arr.size(); i++) {
        cout << "i=" << i << ", arr[" << i << "]=" << arr[i];
        cout << ", candidate=" << candidate;
        cout << ", count=" << count;
        
        if (arr[i] == candidate) {
            count++;
            cout << " → Same, count++";
        } else {
            count--;
            cout << " → Different, count--";
            
            if (count == 0) {
                candidate = arr[i];
                count = 1;
                cout << " → New candidate!";
            }
        }
        cout << "\n";
    }
    
    // Verify candidate is actually majority
    count = 0;
    for (int x : arr) {
        if (x == candidate) count++;
    }
    
    if (count > arr.size() / 2) {
        return candidate;
    }
    
    return -1;  // No majority
}

int main() {
    vector<int> arr = {3, 3, 4, 2, 3};
    
    cout << "Array: ";
    for (int x : arr) cout << x << " ";
    cout << "\n\n";
    
    int majority = findMajority(arr);
    
    cout << "\n━━━━━━━━━━━━━━━━━━━━━\n";
    
    if (majority != -1) {
        cout << "Majority element: " << majority << "\n";
        
        // Count occurrences
        int count = 0;
        for (int x : arr) {
            if (x == majority) count++;
        }
        cout << "Appears " << count << " times out of " << arr.size();
        cout << " (>" << (arr.size()/2.0) << ")\n";
    } else {
        cout << "No majority element found.\n";
    }
    
    return 0;
}
```

### Code: Trapping Rainwater (Using Prefix/Suffix Max)

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> height = {0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1};
    int n = height.size();
    
    // Calculate left max for each position
    vector<int> leftMax(n);
    leftMax[0] = height[0];
    for (int i = 1; i < n; i++) {
        leftMax[i] = max(leftMax[i-1], height[i]);
    }
    
    // Calculate right max for each position
    vector<int> rightMax(n);
    rightMax[n-1] = height[n-1];
    for (int i = n - 2; i >= 0; i--) {
        rightMax[i] = max(rightMax[i+1], height[i]);
    }
    
    // Display elevation and water calculation
    cout << "Elevation map:\n";
    cout << "─────────────\n";
    
    // Print from top to bottom
    int maxHeight = *max_element(height.begin(), height.end());
    
    for (int level = maxHeight; level >= 1; level--) {
        for (int i = 0; i < n; i++) {
            if (height[i] >= level) {
                cout << "█";
            } else {
                // Check if water can be trapped
                int waterLevel = min(leftMax[i], rightMax[i]);
                if (waterLevel >= level) {
                    cout << "~";  // Water
                } else {
                    cout << " ";  // Air
                }
            }
        }
        cout << "\n";
    }
    
    // Calculate total water
    int totalWater = 0;
    
    cout << "\nPosition analysis:\n";
    cout << "Pos  Height  LeftMax  RightMax  Water\n";
    cout << "──────────────────────────────────────\n";
    
    for (int i = 0; i < n; i++) {
        int waterLevel = min(leftMax[i], rightMax[i]);
        int water = waterLevel - height[i];
        totalWater += water;
        
        cout << i;
        if (i < 10) cout << "    ";
        else cout << "   ";
        
        cout << height[i] << "       ";
        cout << leftMax[i] << "        ";
        cout << rightMax[i] << "         ";
        cout << water << "\n";
    }
    
    cout << "\n━━━━━━━━━━━━━━━━━━━━━━━━━━━━\n";
    cout << "Total water trapped: " << totalWater << " units\n";
    
    return 0;
}
```

## 🎯 Prefix Product

Sometimes we need **products** instead of sums!

```
Array:     [2,  3,  4,  5]

Prefix product:
Position 0: 2                   = 2
Position 1: 2 × 3               = 6
Position 2: 2 × 3 × 4           = 24
Position 3: 2 × 3 × 4 × 5       = 120

Result:    [2,  6,  24, 120]
```

---

### Code: Prefix Product

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> arr = {2, 3, 4, 5};
    int n = arr.size();
    
    vector<long long> prefixProduct(n);
    
    prefixProduct[0] = arr[0];
    
    for (int i = 1; i < n; i++) {
        prefixProduct[i] = prefixProduct[i-1] * arr[i];
    }
    
    cout << "Array:          ";
    for (int x : arr) cout << x << "   ";
    cout << "\n";
    
    cout << "Prefix product: ";
    for (auto x : prefixProduct) {
        if (x < 10) cout << x << "   ";
        else if (x < 100) cout << x << "  ";
        else cout << x << " ";
    }
    cout << "\n\n";
    
    cout << "Calculation breakdown:\n";
    for (int i = 0; i < n; i++) {
        cout << "prefixProduct[" << i << "] = ";
        for (int j = 0; j <= i; j++) {
            cout << arr[j];
            if (j < i) cout << " × ";
        }
        cout << " = " << prefixProduct[i] << "\n";
    }
    
    return 0;
}
```

## 📝 Summary Cheat Sheet

```
┌─────────────────────────────────────────────┐
│     Prefix, Suffix & Subarray Guide         │
└─────────────────────────────────────────────┘

PREFIX:
  - Starts from beginning
  - Goes up to position i
  - prefix[i] = sum(arr[0..i])

SUFFIX:
  - Starts from position i
  - Goes to end
  - suffix[i] = sum(arr[i..n-1])

SUBARRAY:
  - Any contiguous portion
  - From index L to R
  - sum(L,R) = prefix[R] - prefix[L-1]

COUNT OF SUBARRAYS:
  - Total = n*(n+1)/2

TIME COMPLEXITIES:
  - Build prefix: O(n)
  - Query range sum: O(1)
  - Brute force range: O(n)
```
